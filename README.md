# Kenshō 検証

A bilingual (Japanese / English) enterprise-support RAG assistant that verifies
every sentence it writes against the passages it retrieved — and refuses to
answer when it cannot.

> Status: scaffold. Implementation follows in phase order (corpus and
> chunking, retrieval and generation, evaluation, ablations, verification,
> self-correction, serving) — each phase adds its own README section as it
> lands.
